REFERENCE/COMPONENTS

UCISInteractionObjectComponent

MODULECharacterInteractionSystemINCLUDEComponents/CISInteractionObjectComponent.hPARENTUActorComponent

Makes an actor usable by a character. It holds the object's state as a gameplay tag, its usable flag and its sides, each with a move handler and an action for each state. It also runs the delegates of a state change and of the start and the end of a use. The actor must replicate for the other players to see the state.

void SetObjectState(const FGameplayTag& NewState)

Changes the object's state. Call it on the server. On a client's copy of the object (a simulated proxy, also while the client's controller owns the actor during a use) the change stays on that copy and a warning is logged once; an autonomous proxy also sends the call to the server. OnObjectStateChangedDelegate runs on every machine where the state changes. On the server it runs only when the state differs from the current one.

void SetUsable(bool bValue)

Sets the usable flag (bUsable). The same rule as SetObjectState applies: call it on the server. On a client's copy (a simulated proxy) it changes only that copy, with one warning; an autonomous proxy also sends the call to the server. Writing bUsable directly, instead of calling this, is not safe while Manage Owner Dormancy is on.

Events

FCISOnObjectStateChanged OnObjectStateChangedDelegate
(FGameplayTag NewState)

Runs when the object's state changes, with the new state. It runs on every machine: where SetObjectState changes the state (on the server, and on a client for its own copy), on clients when the replicated state arrives, and where an Action sets its new state. On a client it can run twice with the same state: when the replicated state arrives first and the client's own Action then sets the same state. A replicated value equal to the client's own state runs nothing. Make the bound code safe to run twice. Bind it to move the object's parts, for example to set the pose of an animation.

Category
CIS|Delegates
FCISUseObjectStartDelegate OnUseStartedDelegate
(ACharacter* Character, UCISCharacterInteractionComponent* CharacterInteractionComponent, UCISInteractionObjectComponent* InteractionObjectComponent)

A use of this object started, on each machine where the use runs (UCISUseExecution: the user's machine, the server and the clients that show the use). Fires after the data object's OnObjectUseStarted, before the move handler starts.

Category
CIS|Delegates
FCISUseObjectActionStartDelegate OnActionStartedDelegate
(UCISInteractionObjectAction* Action, ACharacter* Character, UCISCharacterInteractionComponent* CharacterInteractionComponent, UCISInteractionObjectComponent* InteractionObjectComponent)

The action of a use of this object starts, on the machines that run the action (its NetExecutionPolicy): after the data object's OnObjectActionStarted, before the action's StartInteractionObjectAction.

Category
CIS|Delegates
FCISUseObjectEndDelegate OnUseFinishedDelegate
(ACharacter* Character, UCISCharacterInteractionComponent* CharacterInteractionComponent, UCISInteractionObjectComponent* InteractionObjectComponent, bool bInterrupted)

A use of this object ended (bInterrupted: it was interrupted), after the data object's OnObjectUseFinished and after the object was released, before the character's OnEndUseObjectDelegate. Not fired when the object component itself is gone. On the authority (a standalone game, the server, a listen host) the use is released then: the in-use flag is false, the use state (GetUseState) no longer names it and the actor has its previous owner back. On the user's client the in-use flag is false and the previous owner is back; GetUseState is the replicated value. On a client that shows the use both the in-use flag and GetUseState are the replicated values and can still name the user.
