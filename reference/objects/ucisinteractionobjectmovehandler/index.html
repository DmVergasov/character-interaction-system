UCISInteractionObjectMoveHandler

MODULECharacterInteractionSystemINCLUDEInteractionObjectMoveHandlers/CISInteractionObjectMoveHandler.hPARENTUCISReplicatedObject

Moves the character for a use of an interaction object: it walks the character to a point, turns it, or both. Derive a Blueprint from it, override StartMovement, and call FinishMovement when the movement is done. The side's Action starts after that call, unless the side starts its Action in parallel with the movement.

Functions

AUTHORITY · server, every machineLOCAL · this machinePURE · read only
void FinishMovement()

Ends the movement and runs MovementFinished once. A call while no movement runs, before its start or after its end, does nothing; the plugin logs such a call at the Verbose level of CISLog.

Category
CIS|InteractionObjectMoveHandler
void StartMovement(ACharacter* InteractionCharacter, UCISCharacterInteractionComponent* CharacterInteractionComponent, UCISInteractionObjectComponent* InteractionObjectComponent, UPARAM(ref) const FCISInteractionObjectSide& InteractionObjectSide)

Runs when the movement starts, at the Moving phase of the use, on each machine that runs the handler. Start the movement here, and call FinishMovement when it is done.

void HandlerTick(float DeltaTime, ACharacter* InteractionCharacter, UCISCharacterInteractionComponent* CharacterInteractionComponent, UCISInteractionObjectComponent* InteractionObjectComponent, UPARAM(ref) const FCISInteractionObjectSide& InteractionObjectSide)

Runs every frame from the start of the movement until FinishMovement, and after it as well when Continue Tick After Finish Movement is on, for as long as the object is in use. DeltaTime is the frame time.

void MovementAborted(ACharacter* InteractionCharacter, UCISCharacterInteractionComponent* CharacterInteractionComponent, UCISInteractionObjectComponent* InteractionObjectComponent, UPARAM(ref) const FCISInteractionObjectSide& InteractionObjectSide)

Runs when the use is interrupted, so the handler can undo what it did to the character. A handler that is shared between uses is told even after its movement has finished.

void MovementFinished(ACharacter* InteractionCharacter, UCISCharacterInteractionComponent* CharacterInteractionComponent, UCISInteractionObjectComponent* InteractionObjectComponent, UPARAM(ref) const FCISInteractionObjectSide& InteractionObjectSide)

Runs once, when FinishMovement ends the movement. The side's Action starts after this, unless the side starts it in parallel.

bool IsMovementFinished() const
PURE

True once FinishMovement has ended the movement.
