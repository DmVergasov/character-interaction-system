What's in the box

Character interaction component

Goes on the character: finds the objects in reach, picks the one to use and runs the hold and the use.

UCISCharacterInteractionComponent

Interaction object component

Makes an actor usable: the sides it is used from, its state as a gameplay tag, and what each side does in each state.

UCISInteractionObjectComponent

Actions

What a use does, such as playing a montage or picking up an item. A finished Action can set the object's next state.

UCISInteractionObjectAction

Move handlers

Bring the character into place before or while the Action runs.

UCISInteractionObjectMoveHandler

Conditions

Decide whether a character may use an object. The server can check them again before it accepts a use.

UCISInteractionObjectCondition

Choosing the object

Tests that score the objects in reach, so the character uses the best one.

UCISDetermineUseObjectTest

Data objects

Link one character to one object it can use: the side it uses and Blueprint events at each stage of a use.

UCISInteractionDataObject

Widgets and icons

Show an object's icon on screen with the widget component and the plugin's widgets.

UCISWidgetComponent

Component references

Name a component of an actor, and a socket, in the Details panel; the plugin finds it at run time.

FCISSceneComponentsOnActor

Animation helpers

Attach a mesh to a socket for the length of an anim notify, and move a character with root motion.

UCISAnimNotifyStateAttachMesh

Multiplayer

Where Actions and MoveHandlers run, how the server checks a use, and the project's network settings.

ECISNetExecutionPolicy

Three steps to a usable object

  1. Add UCISCharacterInteractionComponent to your character.

  2. Add UCISInteractionObjectComponent to the actor to use. Give it a side with an Action for the object's state.

  3. Call TryUseObject from your use input.
