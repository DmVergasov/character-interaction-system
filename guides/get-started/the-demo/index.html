GET STARTED/THE DEMO

The demo

The plugin ships a demo map, /CharacterInteractionSystem/Demo/Levels/CISExampleMap. It has a playable character and about twenty interaction objects: doors, levers, a switch, a button, code locks, crates, a gate, a valve, a hand scanner and pick-up items. Open it to see each object work before you build your own, and to find the classes and tags you can reuse.

Open the demo

Section titled “Open the demo”
  1. In the Content Browser, open Settings and turn on Show Plugin Content and Show Engine Content.
  2. Open the map /CharacterInteractionSystem/Demo/Levels/CISExampleMap.
  3. Click Play. The demo character starts at the map’s player start. Walk up to an object: when the character can use it, the prompt E | INTERACT appears above it. Press E to use it.

Controls

Section titled “Controls”

The demo maps these keys and buttons through its input mapping /CharacterInteractionSystem/Demo/Input/IMC_CISDemo.

  • Move and look with the keyboard and mouse or with the gamepad, through IA_CISDemo_Move and IA_CISDemo_Look. Space jumps (IA_CISDemo_Jump), and Left Shift runs.
  • E uses the object in front of the character. Pressing E a second time interrupts a use that is set to stop on a second press. Letting go of E interrupts a use that is set to stop on release.
  • The gamepad’s bottom face button does the same as E.
  • V switches the camera, and 1 restarts the level.

Demo classes

Section titled “Demo classes”

The demo classes are plugin assets in the folders below. Use them as they are, or as the parent of your own Blueprint.

Each group gives its folder under the plugin’s content root, CharacterInteractionSystem, which holds the demo.

  • Actions, folder Demo/Blueprints/InteractionObjectActions: BP_PlaySoundAction plays a sound (its Sound variable), BP_InteractionObjectActionPlayMontage plays a montage on the character and on the object, BP_InteractionObjectActionPickUp plays one of three pick-up montages, and BP_CodeLockAction is the code lock’s action.
  • Move handlers, folder Demo/Blueprints/InteractionObjecMoveHandlers: BP_BaseMoveHandler is the parent of the other two. BP_MoveToComponentMoveHandler walks the character to a component of the object, and BP_MoveToDistanceMoveHandler walks it a set distance (its Move Distance variable).
  • Conditions, folder Demo/Blueprints/InteractionObjectConditions: BP_InteractionObjectCondition_IsObjectRendered lets only BP_CISCharacter use an object, BP_InteractionObjectConditionDIstanceCheck checks the distance, and BP_InteractionObjectConditionTrace checks that the object is in sight.
  • Use test, folder Demo/Blueprints/DetermineUseObjectTests: BP_DetermineObjectTest_InCameraView scores objects by whether they were recently rendered, and reads the first-person camera of BP_CISCharacter. The distance test BP_DetermineObjectTest_Distance is in the folder Content/Blueprints, not in Demo.
  • Data objects: BP_CISDataObject, in folder Demo/Blueprints, is the data object of the demo character. BP_DataObject_LoackedDoor, in folder Demo/Blueprints/InteractionObjects, is the data object of the locked door.
  • Objects, folder Demo/Blueprints/InteractionObjects: the doors, lever, switch, button, code locks, crates, gate, hand scanner, valve and pick items. BP_InteractionDoor is built on BP_BaseInteractObject.
  • Character and game, folder Demo/Blueprints: BP_CISCharacter is the demo character, BP_CISGameMode is the demo game mode and BP_CISHUD is its HUD, which draws the E | INTERACT prompt.

Demo tags

Section titled “Demo tags”

The plugin defines these 17 tags in its runtime module, so they exist in every project that has the plugin. The demo uses them as object states. To use them in your own objects, pick them in the state fields; you do not need to add them to Project Settings › GameplayTags.

Use the demo in your project

Section titled “Use the demo in your project”
  • You can take the demo’s action, condition and data object classes, and its tags, into your own project. The tags come with the plugin. The move handlers work only with BP_CISCharacter.
  • The demo’s objects are tied to the demo character. Its move handlers move only BP_CISCharacter, and most demo objects have BP_InteractionObjectCondition_IsObjectRendered in Usable Conditions, which lets only BP_CISCharacter use them. The camera use test BP_DetermineObjectTest_InCameraView also reads the first-person camera of BP_CISCharacter, so it does not suit another character. Your own character cannot use these objects. Test your character with your own objects, as in Your own character.
  • The E | INTERACT prompt comes from BP_CISHUD, the demo game mode’s HUD. In your own game mode there is no prompt until you add one.
